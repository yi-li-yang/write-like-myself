
# Write like myself

This is a repo to create a skill to guide AI agents to write like myself (and even better).

To do this, we need some backgrounds and writing examples,

- https://yi-li-yang.github.io/ this is my webpage
- https://orcid.org/my-orcid?orcid=0000-0002-1791-3899 this is my ORCID

These should provide enough materials for the agent to form a writing style.

I also include a folder RTSV2_METHODS in the workspace, this project is entirely written with ClaudeCode in VSCode, there are markdown files that recorded my writing preference and collaboration preference with AI.

There are some existing scientific-writing skills and books and materials online, look at them and find useful information to include.

Finally, this skill should not be rule-based, design this skill elegantly so that it is not simply a collection of many writing rules.

Also Gmail and Drive access give you example of daily writing
